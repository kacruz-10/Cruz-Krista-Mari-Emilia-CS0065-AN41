# Case-Based Reasoning System: Disaster Response Decision Support System

This project implements a Case-Based Reasoning (CBR) system in Python to assist local government units with disaster response decisions by retrieving past disaster cases, adapting solutions based on population size, and retaining new learning experiences.

## Files
- `TA3_Cruz.ipynb` - Python script containing the complete CBR cycle (Retrieve, Reuse, Revise, Retain)
- `TA3_Cruz.pdf` - Step-by-step evidence documentation and pair reflection

## CBR Cycle Steps Implemented
- **Retrieve** (Weighted attribute similarity scoring)
- **Reuse & Revise** (Population ratio scaling and urban tactical adjustments)
- **Retain** (Dynamic case base expansion)

## How to Run
1. Open Google Colab or your preferred Python environment.
2. Copy and paste the code from `TA3_Cruz.ipynb`.
3. Run the cell to view similarity ranking, adapted solutions, and the updated case base.
