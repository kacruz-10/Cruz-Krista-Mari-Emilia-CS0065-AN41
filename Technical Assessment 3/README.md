MACHINE PROBLEM: Rule-Based Agent Simulation

This project implements a rule-based vacuum cleaner agent in Python that perceives and cleans an environment consisting of multiple rooms.

## Files
- `TA2_Cruz.ipynb` - Python script containing the rule-based agent and simulation logic
- `TA2_Cruz.pdf` - Completed technical assessment document with code and outputs

## Features
- **Environment Setup:** Initializes rooms and allows users to set their initial states (`Dirty` or `Clean`)[cite: 5, 8].
- **Rule-Based Agent:** Evaluates room states, cleans dirty rooms, and intelligently navigates between spaces[cite: 4, 7].
- **Simulation Control:** Runs the agent through a user-defined number of steps and monitors environment states[cite: 6].
