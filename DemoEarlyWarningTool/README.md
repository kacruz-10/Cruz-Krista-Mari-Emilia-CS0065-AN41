# MACHINE PROBLEM 1: Early Warning Tool Using KNIME

This project uses the KNIME Analytics Platform to build and evaluate machine learning models that predict student risk status (`At Risk` or `Not At Risk`) based on academic performance.

## Files Inside Project Folder
* `DemoEarlyWarningTool.knwf` - Exported KNIME workflow file.
* `student_performance_knime.csv` - Dataset used by the workflow containing student academic records.
* `CRUZ_Machine Problem 1.pdf` - Step-by-step documentation of the project.
* `README.md` - Project description and instructions.

## Algorithms Compared
* Decision Tree
* Logistic Regression
* Random Forest

## How to Run the Workflow
1. Import the `.knwf` workflow file into the KNIME Analytics Platform.
2. Configure the CSV Reader node and select the included `student_performance_knime.csv` dataset.
3. Execute all nodes in the workflow.
4. Open the Scorer nodes to review and compare evaluation metrics.
